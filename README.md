# Paradise Nursery Shopping Application

Welcome to **Paradise Nursery**, your one-stop shop for high-quality houseplants. This application allows users to explore a vast collection of plants, categorize them by their benefits, and manage a digital shopping cart.

## Project Overview
This project was developed using React and Redux Toolkit to demonstrate modern e-commerce functionalities, including:
* **Interactive Landing Page:** A welcoming entrance with a "Get Started" call to action.
* **Product Management:** Over 18 unique plants organized into Air Purifying, Aromatic, and Low Maintenance categories.
* **Shopping Cart Logic:** Seamlessly add, remove, and update plant quantities with real-time cost calculation.

## How to Run
1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev` to start the local development server.
